# 选目录白屏

日期：2026-08-16  
范围：同域 WebUI 的工作区目录选择器（Miller）+ `ki serve` 静态路由

## 现象

在「选择工作区目录」里点某一层（复现路径类似 `/` → `data` → `hgy` → `tmp`）后，整页变成空白。浏览器地址栏仍是 `http://localhost:19800/` 或变成宿主路径（例如 `/data/hgy/tmp`）。侧栏、对话、对话框全部消失，只剩空的 `<div id="root">`。

同时「新建文件夹」点了像没反应。

WebUI 经常经 SSH / IDE **端口转发**打开，不是只在本机 `127.0.0.1` 上用。这也是当初不用系统原生选目录、改成自绘对话框的原因。

## 时间线

1. 第一版选择器把宿主绝对路径（`/home/hgy`、`/data/hgy/tmp`）暴露在可点击的面包屑 / 行上，部分手势会让浏览器把这些路径当成 **HTTP 路径** 去 GET。
2. `serveUI` 对「路径里没有 `.`」的请求一律回 SPA 的 `index.html`。地址变成 `/data/hgy/tmp` 后，模块脚本仍是 `/assets/index-….js`，在端口转发或中间层改写路径时，资源对不上，页面空白。
3. 第一次修补改成：未知路径 **302 到 `/`**。本机有时能救回来，转发场景下 `Location: /` 会落到转发入口的根，而不是 `ki` 那一跳，仍然白屏。
4. 第二次：未知非资源路径 **就地 200 出 SPA**（不再 302）；行点击只 `fetch /v1/fs`，禁止把宿主路径写进 `href`。
5. 「新建文件夹」对照 DSH：独立弹层 `createPortal` 到 `document.body`，并去掉「正在编辑路径 / loading」时把按钮禁用掉的逻辑。

## 根因

有两件事叠在一起。

### 1. 宿主路径被当成网站路径

选择器操作的是机器上的目录（`/data/hgy/tmp`）。只要这个字符串进了 `href`、或按钮落进隐式 `<form>`、或中间层把点击收成导航，浏览器就会请求：

```
GET /data/hgy/tmp
```

这不是列目录 API。API 应是：

```
GET /v1/fs?path=%2Fdata%2Fhgy%2Ftmp
```

整页 GET 一旦发出，当前 SPA 被卸掉。后面无论 404、302 还是错误的 `index.html`，用户看到的都是「点一下变白」。

### 2. 静态路由把「非资源」处理错了

`serveUI` 只应在 `/` 出页面，在 `/assets/*` 出打包文件。把 `/data/hgy/tmp` 当成 SPA fallback，或对它 302 到 `/`，都默认「浏览器和 ki 在同一个 origin 根上」。端口转发不满足这个默认。

「新建文件夹」是另一条线：弹层写在选择器卡片内部且 `position: absolute`，叠层被挡住；编辑路径时按钮还被 `disabled`。用户以为没点上，和白屏无关，但是同一块 UI。

## 为什么第一次修不好

302 默认「`/` 永远是这颗 SPA」。转发后 `/` 不是 ki。正确做法是：

- 前端：任何点击都不要触发对宿主路径的文档导航。
- 后端：万一还是走到了 `/data/…`，就在 **当前 URL** 上返回 SPA，不要把人送走。

## 现状

| 层 | 做法 |
|---|---|
| 选择器 | 行 / 面包屑是 `type="button"`，`preventDefault`；只 `fetch('/v1/fs?path=')` |
| 打开工作区 | `POST /v1/workspaces`，成功后关对话框、刷新列表，不改 `location` |
| `serveUI` | `/` 和未知非资源路径都 `writeIndex`（200）；存在的 `/assets/*` 原样出文件 |
| 崩溃 | `ErrorBoundary` 显示错误，而不是空白 root |
| 新建文件夹 | 与 DSH 一样，单独 Modal 挂到 `document.body`（`z-index` 高于选择器） |

约束写在 `AGENTS.md`：端口转发是正式客户端；只用同域相对的 `/v1`、`/assets`；不要把宿主文件路径写进 `href`；不要用系统选目录。

## 教训

- 磁盘路径和 URL 路径长得像，不能共用一套点击模型。列目录只走带 query 的 API。
- 为本机 origin 写的 302 / 绝对 `/` 在转发下会指错地方。优先「不导航」；fallback 是就地出 SPA，不是重定向。
- 自绘选择器的弹层要和 DSH 一样挂到 `document.body`，不要指望卡片内部的 `absolute` 盖过页脚和遮罩。
- 白屏要留一条肉眼能看见的错误（ErrorBoundary），否则只能靠截图猜。

## 未做

- 没有对选择器的每一次点击做「禁止出现 `GET /data/…`」的 e2e（可以用 Playwright 断言不发生该请求）。
- 没有按转发前缀（`/ki/`）重写 `/assets`。当前假设转发的是 **端口**，不是路径前缀。
